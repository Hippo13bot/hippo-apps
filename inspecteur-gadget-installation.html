Installer Inspecteur Gadget
sur ton ordinateur.

Ce guide t’accompagne de l’installation jusqu’à l’ajout de ta clé IA pour l’analyse d’images, avec toutes les étapes de sécurité du Mac. Les assistants IA peuvent t’aider, mais l’installation reste sous ton contrôle.

Choisir mon téléchargement ↓
Compatibilité : le fichier Mac (.dmg) fonctionne sur tous les Macs, Intel comme Apple Silicon. Un installateur .exe est aussi disponible pour Windows. Ne partage jamais tes mots de passe ni tes clés API.

1. Télécharger Inspecteur Gadget

Sur Mac
  1. Dans la fiche Inspecteur Gadget de HIPPO APPS, clique sur Tous les Macs.
  2. Le fichier téléchargé s’appelle Inspecteur.Gadget-1.0.1-arm64.dmg. Il se trouve dans ton dossier Téléchargements.
  3. Si ton navigateur demande « Conserver » ou « Autoriser » le téléchargement, vérifie que le nom correspond, puis accepte.
Sur Windows
  1. Dans la fiche, clique sur Windows.
  2. Le fichier s’appelle Inspecteur.Gadget.Setup.1.0.1.exe.

2. Installer sur Mac

  1. Double-clique sur le fichier .dmg : une fenêtre s’ouvre, comme un petit disque.
  2. Fais glisser l’icône Inspecteur Gadget sur le dossier Applications dans cette même fenêtre.
  3. Attends la fin de la copie, puis éjecte le disque : clic droit sur le disque Inspecteur Gadget dans le Finder (colonne de gauche), puis Éjecter.
  4. Ouvre le dossier Applications et lance Inspecteur Gadget. Au premier lancement, macOS peut afficher une alerte : passe à l’étape suivante.

3. Sécurité macOS : ouvrir l’application sans désactiver les protections

Transparence : cette application n’est peut-être pas notariée par Apple. Dans ce cas, macOS affiche un avertissement au premier lancement, ce qui est normal pour une application indépendante. Cela ne veut pas dire qu’elle est dangereuse, mais cela veut dire que c’est à toi de vérifier la source. Les étapes ci-dessous vont de la plus simple à la plus avancée : arrête-toi dès que l’application s’ouvre.

Étape A : vérifier la source
  1. Télécharge Inspecteur Gadget uniquement depuis le bouton officiel de HIPPO APPS, qui renvoie vers la publication GitHub du projet.
  2. Si le fichier vient d’ailleurs, si son nom est différent ou si tu as un doute, ne l’ouvre pas et supprime-le.
  3. Si macOS indique qu’il a détecté un logiciel malveillant, supprime le fichier et ne passe pas aux étapes suivantes.
Étape B : clic droit, puis Ouvrir
  1. Dans le dossier Applications, fais un clic droit (ou Ctrl + clic) sur Inspecteur Gadget.
  2. Choisis Ouvrir, lis l’avertissement et confirme avec Ouvrir si tu as vérifié la source.
Étape C : Réglages Système → « Ouvrir quand même »

Sur les versions récentes de macOS (Sequoia 15 et suivantes), le clic droit ne suffit souvent plus. Dans ce cas :

  1. Essaie d’ouvrir l’application une fois (elle sera bloquée, c’est normal), puis clique sur OK ou Terminé dans l’alerte.
  2. Ouvre le menu Pomme → Réglages Système → Confidentialité et sécurité.
  3. Descends jusqu’à la rubrique Sécurité. Un message indique qu’Inspecteur Gadget a été bloqué. Clique sur Ouvrir quand même.
  4. Saisis ton mot de passe Mac ou utilise Touch ID, puis confirme avec Ouvrir. Ce bouton reste affiché environ une heure après la tentative d’ouverture : si tu ne le vois plus, recommence l’étape 1.
Étape D : utiliser Terminal (seulement si les étapes A à C échouent)

Si macOS affiche « Inspecteur Gadget est endommagé et ne peut pas être ouvert » ou « le développeur ne peut pas être vérifié » et que le bouton « Ouvrir quand même » n’apparaît pas, la cause est presque toujours l’étiquette de quarantaine que macOS ajoute aux fichiers téléchargés. Tu peux retirer cette étiquette sur cette application uniquement, sans désactiver aucune protection de ton Mac.

  1. Vérifie que l’application est bien dans le dossier Applications (étape 2) et que tu as contrôlé la source (étape A).
  2. Ouvre Terminal : appuie sur Cmd + Espace, tape Terminal, puis appuie sur Entrée.
  3. Tape exactement le texte ci-dessous, en laissant un espace à la fin, sans appuyer sur Entrée : 
    xattr -dr com.apple.quarantine
  4. Dans le Finder, ouvre Applications, puis fais glisser l’icône Inspecteur Gadget dans la fenêtre Terminal. Le chemin de l’application s’écrit tout seul à la suite de la commande. Tu dois obtenir quelque chose comme : 
    xattr -dr com.apple.quarantine /Applications/Inspecteur\ Gadget.app
  5. Appuie sur Entrée. Si Terminal n’affiche rien de plus, c’est que la commande a fonctionné.
  6. Relance Inspecteur Gadget depuis le dossier Applications.

Si Terminal répond « Operation not permitted », va dans Réglages Système → Confidentialité et sécurité → Accès complet au disque, active Terminal, ferme puis rouvre Terminal et recommence. Tu pourras désactiver cet accès ensuite.

Règles de prudence avec Terminal : ne copie jamais une commande trouvée au hasard sur Internet ou envoyée par un inconnu. La commande ci-dessus est la seule utilisée dans ce guide : elle retire uniquement l’étiquette « téléchargé depuis Internet » d’Inspecteur Gadget. Ne désactive jamais Gatekeeper (commandes spctl --master-disable ou équivalents) et ne tape jamais ton mot de passe dans une commande que tu ne comprends pas.

Autorisations demandées par macOS
  1. Selon ce que tu fais dans l’application, macOS peut demander l’accès à certains dossiers (Bureau, Documents, Téléchargements), aux photos ou à des fichiers externes. Accepte uniquement ce qui est nécessaire pour analyser les images que tu choisis.
  2. Tu peux changer ces choix à tout moment dans Réglages Système → Confidentialité et sécurité (rubriques « Fichiers et dossiers », « Photos », etc.).
  3. Garde macOS à jour : les mises à jour corrigent des failles de sécurité.

4. Installer sur Windows

  1. Ouvre Inspecteur.Gadget.Setup.1.0.1.exe depuis ton dossier Téléchargements.
  2. Si Windows affiche « Windows a protégé votre ordinateur » (SmartScreen), clique sur Informations complémentaires. Vérifie le nom du fichier, puis clique sur Exécuter quand même uniquement si tu as téléchargé le fichier depuis le bouton officiel HIPPO APPS.
  3. Suis l’assistant d’installation.
  4. Lance Inspecteur Gadget depuis le menu Démarrer ou le raccourci créé.

5. Ajouter ta clé IA pour l’analyse d’images

Pour analyser tes images, Inspecteur Gadget utilise une IA. Il a besoin de ta clé API : un long code secret, propre à toi, qui permet à l’application d’utiliser l’IA en ton nom. Une clé API est différente d’un mot de passe et différente d’un abonnement ChatGPT, Claude ou Gemini : elle se crée sur le site « développeurs » du fournisseur et l’usage est facturé à part, selon ce que tu utilises.

A. Créer ta clé

Utilise le fournisseur que l’application te propose dans ses réglages. Voici où créer une clé pour les principaux :

  • Anthropic (Claude) : console.anthropic.com → Settings → API Keys → Create Key. La clé commence par sk-ant-.
  • OpenAI (ChatGPT) : platform.openai.com/api-keys → Create new secret key. La clé commence par sk-.
  • Google (Gemini) : aistudio.google.com/apikey → Create API key.
  1. Connecte-toi ou crée un compte chez le fournisseur choisi.
  2. Vérifie la rubrique de facturation (Billing) : ajoute des crédits ou un moyen de paiement si le fournisseur l’exige, et fixe si possible une limite de dépense mensuelle.
  3. Crée la clé et copie-la immédiatement : la plupart des sites ne l’affichent qu’une seule fois. En cas de perte, crée-en simplement une nouvelle.

B. La coller dans Inspecteur Gadget

  1. Ouvre Inspecteur Gadget, puis ses Réglages / Paramètres.
  2. Cherche le champ prévu pour la clé (souvent nommé « Clé API », « API key » ou « Clé IA »). Si l’application propose plusieurs fournisseurs, choisis d’abord celui qui correspond à ta clé.
  3. Colle ta clé avec Cmd + V (Mac) ou Ctrl + V (Windows), puis enregistre.
  4. Teste en analysant une image simple. En cas d’erreur, vérifie que la clé est complète (sans espace avant ou après), qu’elle correspond bien au fournisseur choisi et que ton compte a du crédit.

Garde ta clé secrète : ne l’envoie à personne, ne la publie pas et ne la colle pas dans une conversation, même avec une IA qui t’aide à installer l’application. Si tu penses qu’elle a fuité, supprime-la chez le fournisseur et crée-en une nouvelle. Les images que tu analyses sont envoyées au fournisseur de l’IA : évite d’y mettre des documents confidentiels.

Les noms exacts des menus changent parfois avec les mises à jour des sites et de l’application. Si tu ne trouves pas un bouton, cherche son équivalent ou consulte l’aide du fournisseur.

6. Dépannage rapide

  • « Inspecteur Gadget est endommagé et ne peut pas être ouvert » : reprends l’étape D de la section 3 (commande Terminal sur cette seule application).
  • Le bouton « Ouvrir quand même » n’apparaît pas : essaie d’ouvrir l’application une fois de plus, puis retourne tout de suite dans Réglages Système → Confidentialité et sécurité.
  • Rien ne se passe au double-clic sur le .dmg : attends quelques secondes (macOS vérifie le fichier), puis réessaie. Si le problème continue, retélécharge le fichier.
  • Windows bloque l’installateur : utilise « Informations complémentaires → Exécuter quand même » seulement si le fichier vient du bouton officiel.
  • L’analyse d’image ne fonctionne pas : vérifie ta clé API, ton crédit chez le fournisseur et ta connexion Internet.
